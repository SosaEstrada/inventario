#SISTEMA INVENTARIO
El proyecto fue desarrollado principalmente para el registro y consulta de productos. 

#FUNCIONES PRINCIPALES
* Agregar productos.
* Consultas productos.
* Ver cantidad disponible

#TECNOLOGÌAS IMPLEMENTADAS
Se utilizan las siguientes tecnologìas:
* PHP v.8.4.16
* Html
* CSS 
* MariaDB
* PDO

#REQUERIMIENTOS PARA LA INSTALACIÒN DE LA APLICACIÒN
Para la instalaciòn de la aplicaciòn se necesita instalar:
* PHP en la ùltima versiòn
* VISUAL STUDIO CODE
* XAMPP corriendo
* GESTOR DE BASE DE DATOS
* MYSQL corriendo

#PASOS DE INSTALACIÒN
Se configura e instala con los siguientes pasos:
1. Crea el proyecto en la carpeta htdocs en la carpeta de XAMPP con el nombre "inventario"  (C:\xampp\htdocs\inventario)
2. Acceder al gestor de BD con usuario: root, contraseña:           (sin contraseña).      
3. Crea la BD "inventario" en el gestor.
4. Corre la consulta para crear las tablas.
5. Abre un navegador (de tu preferencia).
6. Pon la direcciòn de la ruta del nombre del proyecto (http://localhost/inventario/).
