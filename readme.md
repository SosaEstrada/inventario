#SISTEMA DE INVENTARIOS

## FUNCIONES PRINCIPALES 
- El proyecto regitra por nombre, cantidad y permite hacer consultas del inventario

## TECNOLOGIAS
- PHP 8.2.12
- Css  
- MySQL
- Visual Studio Code

## INTALACION
- PHP
- Laragon
- Heidi
- Visual Studio Code
- Navegador


## CONFIGURACION
Descarga o clona el repositorio en tu computadora.
Si utilizas Laragon, coloca la carpeta del proyecto dentro de:
C:\Laragon\www\
Por ejemplo:
C:\Laragon\www\inventario\
Si utilizas Laragon, coloca el proyecto dentro de la carpeta correspondiente:
C:\laragon\www\
nicia Apache y MySQL desde Laragon.
Luego, accede a phpMyAdmin y crea una base de datos con el siguiente nombre:
CREATE DATABASE inventario;
Después, selecciona la base de datos agregando al inicio del script SQL:
USE inventario;
Finalmente, ejecuta el resto del script SQL correspondiente al proyecto para crear las tablas necesarias.
